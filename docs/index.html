PillowNet

A C# wrapper for Pillow (PIL) using CSnakes to embed Python in .NET. The API mirrors Pillow's Python design with C# naming conventions.

Get started API reference Feature roadmap View on GitHub
Experimental prototype. This project is a work-in-progress built with the help of "vibe coding". Things will break, features are missing, and it may not be stable enough for production use.

Overview

PillowNet brings Pillow's image-processing power to .NET applications without spawning external Python processes. Call familiar operations from C# or use the bundled CLI for common tasks.

PillowNet.Core

Typed C# API — Image, ImageFilter, ImageDraw, Exif, Watermark, and more — backed by an embedded Pillow runtime.

PillowNet.Cli

Command-line tool for convert, resize, filter, enhance, watermark, EXIF inspection, and other everyday image workflows.

PillowNet.Tests

Automated regression tests run on every test project build (29 tests) to catch lifecycle bugs and API regressions early.

Features

Core Pillow modules are wrapped with IDisposable-aware C# types and a thin Python bridge.

Image I/O & geometry

Open, save, resize, crop, rotate, flip, merge bands, quantize, and pixel-level access.

Filters & enhancements

Blur, sharpen, edge detection, Gaussian blur, and ImageEnhance brightness/contrast/sharpness.

Drawing & color

ImageDraw primitives, fonts, polygons, and ImageColor helpers for RGB and named colors.

ImageOps & morph

Grayscale, posterize, autocontrast, and ImageMorph apply/match operators.

Watermarks

Text and image watermarks with opacity, anchoring, and region removal.

EXIF & metadata

Read and preserve EXIF tags, IFD strings, and typed tag accessors on save.

Sequence & math

Multi-frame images (GIF/WebP) and ImageMath expression evaluation.

CLI tooling

Batch-friendly commands for info, convert, resize, filter, enhance, and watermark workflows.

Architecture

C# calls into a Python module via CSnakes; Pillow does the heavy lifting under the hood.

PillowNet.Cli / your app System.CommandLine or direct C# API usage
↓
PillowNet.Core Image, ImageFilter, ImageDraw, Exif, Watermark, …
↓
CSnakes runtime Embeds CPython; manages PyObject lifetimes from C#
↓
pillow_bridge.py Typed Python functions that call Pillow APIs
↓
Pillow (PIL) Decode, transform, encode images

Solution layout

Project Role
PillowNet.Core C# wrappers + pillow_bridge.py + CSnakes bootstrap
PillowNet.Cli CLI entry point referencing Core
PillowNet.Tests xUnit regression suite with shared PillowFixture

How it works

  1. Initialize once PillowEnvironment.Initialize() boots CSnakes and loads Pillow via pip on first run.
  2. Open an image Image.Open(path) returns a disposable handle to a Pillow Image object.
  3. Transform Resize, filter, draw, or enhance — each operation crosses the bridge and returns new wrappers.
  4. Save or inspect Write output files, read EXIF, or query pixels; dispose wrappers when done.

Quick start

Prerequisites

  • .NET 10 SDK
  • Network access on first run (CSnakes downloads Python and installs Pillow)

Build & test

dotnet build
dotnet test

Building PillowNet.Tests also runs the test suite automatically. Disable with -p:RunTestsAfterBuild=false if needed.

C# API

using PillowNet;

PillowEnvironment.Initialize();

using var image = Image.Open("input.jpg");
using var resized = image.Resize((800, 600), Resampling.Lanczos);
using var filtered = resized.Filter(ImageFilter.Sharpen);
filtered.Save("output.jpg");

CLI examples

# Image metadata
dotnet run --project PillowNet.Cli -- info photo.jpg

# Convert format / color mode
dotnet run --project PillowNet.Cli -- convert input.png output.jpg --format JPEG

# Resize and filter
dotnet run --project PillowNet.Cli -- resize input.jpg out.jpg -w 800 -h 600 --resample Lanczos
dotnet run --project PillowNet.Cli -- filter input.jpg blurred.jpg --filter GaussianBlur --radius 4

# Watermark
dotnet run --project PillowNet.Cli -- watermark-text input.jpg out.jpg -t "Copyright" --opacity 0.4
  • info — print dimensions, mode, format
  • convert — change format or color mode
  • resize / thumbnail — geometry
  • filter — Pillow ImageFilter presets
  • enhance — ImageOps / ImageEnhance
  • draw — rectangles, text, polygons
  • exif — read metadata tags
  • watermark-text / watermark-image / watermark-remove
  • pixel — get or set individual pixels
  • sequence — multi-frame GIF/WebP frames
